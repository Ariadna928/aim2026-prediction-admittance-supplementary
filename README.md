# Supplementary Material

This repository contains supplementary videos and representative images for the paper:

**Predictor Structure and Closed-Loop Stability in Variable Admittance Control for Dynamic Contact Interaction**

Accepted at the **2026 IEEE/ASME International Conference on Advanced Intelligent Mechatronics (AIM 2026)**.

## Contents

- `videos/`: demonstration videos of the Koopman-based variable admittance controller during paragraph writing.
- `images/`: representative images of the experimental setup and handwriting task.

Additional experimental data are available from the authors upon reasonable request.
